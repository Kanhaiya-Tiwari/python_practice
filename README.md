# Python Practice Repository

This repository is a hands-on Python learning project covering the basics of Python programming, control flow, strings, collections, functions, exception handling, and modules.

It is designed for practice, revision, and interview preparation.

## Project Goals

- Learn Python fundamentals step by step
- Practice coding exercises and examples
- Prepare for technical interviews
- Build confidence with real examples and small scripts

## Repository Structure

- `1_phase_introduction.py` - Introduction and basic Python concepts
- `2_phase_loops.py` - Loops and iteration
- `3_phase-string.py` - String operations and interview questions
- `4_phase_Collections.py` - Lists, tuples, dictionaries, sets
- `5_phase_functions.py` - Functions, arguments, lambda, recursion
- `6_phase_Exception Handling.py` - Exception handling and custom exceptions
- `7_phase_Modules & Packages.py` - Modules and packages
- `aws_s3_utitlite.py` - S3-related utility script
- `example.py`, `file.py`, `json.py`, `request.py` - Practice scripts for different Python topics

## Setup

Navigate to the project folder and activate the virtual environment:

```bash
cd /Users/kanha/DevOps/python-practice/python_practice
source .venv/bin/activate
```

If your system uses `python3`, run:

```bash
python3 1_phase_introduction.py
```

Or use:

```bash
python 1_phase_introduction.py
```

## Run a File

Example:

```bash
cd /Users/kanha/DevOps/python-practice/python_practice
source .venv/bin/activate
python 2_phase_loops.py
```

## Dependencies

This project uses Python and the local virtual environment in `.venv`.

If you want to install extra packages for a specific example, use:

```bash
pip install package-name
```

## Learning Flow

1. Start with `1_phase_introduction.py`
2. Move to loops and conditionals
3. Learn strings and collections
4. Practice functions and scope
5. Understand exceptions and debugging
6. Explore modules and packages

## Notes

- The files are intentionally simple and beginner-friendly.
- Many scripts are built for practice and revision.
- Interview-style questions are included in some phase files as comments.
